# Teleportation Pipeline

This is a conceptual research pipeline for the Aura workbook.

TP-001 Photon — feasible as a simulation target.
TP-002 Electron — experimental/theoretical model.
TP-003 C60 molecule — mesoscopic model.
TP-004 Virus — biological edge case model.
TP-005 Neuron cluster — cognitive-link model.
TP-006 Human — currently infeasible; represented only as a theoretical state-transition model.

Each stage should record assumptions, state representation, fidelity/measurement metrics, simulation seed, and provenance. The workbook must not interpret a simulation as proof of physical feasibility.
