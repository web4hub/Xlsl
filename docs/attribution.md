# Aura XLSL Attribution

**Inventor / project attribution:** Seriki Yakub (KUBU LEE)

Aura XLSL and the Aura Research extensions are intended for research and educational use.

The project distinguishes the XLSL format from implementation code and third-party dependencies. Contributors should preserve attribution in documentation, workbook metadata, and derivative specifications.

## Extension names

- `.xlsl` — Intelligent Spreadsheet Language
- `.xlog` — experimental/provenance logs
- `.xsim` — simulation definitions
- `.xquant` — quantitative/quantum-oriented state descriptions
- `.xdim` — multidimensional data
- `.xphilo` — research reasoning
